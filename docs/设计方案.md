# Wego CAD 设计方案

这份说明记录建模页为什么这样拆，以及每一期做到哪里。产品名是 Wego CAD。界面、文案和图标都是本仓库自己的，不沿用其他 CAD 产品的名称、图标或工程格式。

## 目标

在浏览器里做精确实体建模：草图、拉伸、旋转、布尔、圆角、倒角、抽壳、拔模、薄壁、移动、镜像和阵列。模型默认只留在本机。

对照的是实体建模里常见的那一组操作，不是把某个桌面软件的界面搬进网页。那个产品的页面本身是原生应用的介绍站，内核是 Open CASCADE，视图是原生 OpenGL。网页版把同一类几何能力放到浏览器里，渲染改用 WebGPU。

## 技术选择

| 部分 | 选择 | 原因 |
| --- | --- | --- |
| 几何内核 | Open CASCADE V8，经 occt-wasm 调用 | 拉伸、旋转、布尔、圆角、抽壳、拔模和阵列都有现成的 B-Rep 实现 |
| 加载方式 | 从 URL 加载 wasm | OCCT 是 LGPL-2.1-only。单独加载这份文件，方便替换 |
| 渲染 | Three.js `WebGPURenderer` | 按要求走 WebGPU，不用 WebGL 后备 |
| 界面 | React 19、TypeScript、Vite | 特征树和属性面板是普通界面状态 |
| 线程 | Web Worker | 布尔和剖分不卡住操作 |

occt-wasm 没有浏览器里的交互视图。内核只产出边界表示，再剖成三角网格和边线，交给 WebGPU。边线单独画，实体才有 CAD 的棱边。

坐标单位是毫米，Z 轴朝上。Three.js 的相机 up 也是 Z。

## 架构

```text
React 界面
  文档：草图、特征、实体、撤销栈
  视口：WebGPU 网格、边线、基准面、草图线段

Web Worker
  按特征顺序重放
  每个实体保留一个形状，直到全部剖分完成
  拷贝顶点后再释放 WASM 句柄
```

浏览器只保存特征参数。打开或修改后整树重放，网格只是显示缓存。第一期曾经让每个拉伸各算各的，那对单向拉伸够用。圆角和布尔必须看见上一步的实体，所以从这一期起，重放改成一条顺序记录：形状放在 `bodyId → shape` 的表里，最后再剖分。

特征失败时，错误记在这条特征上，已经生成的实体保持上一步的形状。删除一条特征不会去改内核里的命名，而是少重放这一步。

## 第一期（0.1.0，已完成）

- XY、XZ、YZ 三个基准面。草图的 U 沿平面 x 方向，V 由法向叉乘得到。
- 矩形、圆、封闭多段线、三点圆弧（用弦封成截面）。
- 双向拉伸，半透明预览，拖动端点。
- 特征树、撤销重做、多实体颜色和显隐。

提交 `a547a2d`。

## 第二期（0.2.0，本次）

工具在左侧，参数在右侧。确认或点工具之后，操作写进特征数组。

| 操作 | 记录方式 | 已核对的结果 |
| --- | --- | --- |
| 旋转 | 轴过草图原点，沿 U 或 V。新建、求和或求差 | `(0,10)–(20,30)` 绕 X 轴 360°，体积 `400 × 2π × 20` |
| 并集 / 差集 / 交集 | 结果替换目标实体，工具体隐藏 | 两个 20 mm 方块错开 10 mm：并集 12000，差集 4000，交集 4000 |
| 圆角 / 倒角 | 替换该实体的形状。先所有边，失败则逐边 | 20 mm 方块、半径或距离 2 mm，体积小于原来的 8000 |
| 抽壳 | 去掉法向最接近开口方向的面 | 壁厚 2 mm、开口 +Z，体积 3392 |
| 拔模 | 拉伸特征上的角度，调用 `draftPrism` | 20 mm 方块、8°，体积约 5962 |
| 薄壁 | 矩形和圆向内收；其余截面用二维线偏移 | 40×25、壁厚 2、高度 20，体积 4880 |
| 片体 | 拉伸线框 | 有网格，体积记 0 |
| 移动 / 复制 | 平移。复制另建一个实体 | 体积不变，复制体是新实体 |
| 镜像 | 对基准面做副本 | 对 YZ 镜像后落到 X 负侧 |
| 线性阵列 | 数量包含种子，间距是步长 | 3 个不重叠的 8000 mm³ 方块，体积 24000 |
| 圆周阵列 | 数量包含种子，角度是每步间隔（度） | 4 个、间隔 90°，体积 32000 |

圆角不能靠着一次查询到的边反复用。第一次圆角之后，那些边句柄就失效了，所以失败重试会重新取边。布尔或阵列如果得到复合体，圆角、倒角和抽壳会先取出其中的实体。

拓扑命名用几何身份，不用内核内部编号。圆角记录边的中点、切向和长度。抽壳仍用方向挑面。实体只是平移或旋转时，这些位置可以跟着改；草图如果把那条边挪到别处，特征会说明找不到原来的边。

撤销栈保存的是整份文档。拖动数字时用一次临时锚点，松手只记一步。

## 第三期（0.3.0，本次）

- 偏置、等分、斜基准面。参数存在平面上，显示和草图用解析后的原点和法向。
- 布尔缝合公差。为 0 时仍走原来的精确布尔。
- 整体弦高，以及按面法向单独加密一个面。
- STEP 导入、导出。形状按特征重放，不依赖外部文件。
- 点选单条边倒圆。身份是边上的一点、切向和长度。上游把这条边挪开超过公差时，特征会报「找不到对应的边」，而不会悄悄倒到另一条边上。

还没有装配级的 STEP 颜色和名称，也没有在草图大改之后仍能跟踪「原来那条边」的完整拓扑命名。
