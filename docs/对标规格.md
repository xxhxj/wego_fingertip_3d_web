# 对标指尖 3D 的建模页规格

日期：2026-10-14。状态：已实现。

对标的是 [指尖3D](https://digitcad.top/index.html) 官网公开的建模能力，以及它建模屏的布局：左侧工具轨、选择过滤、视图方块、右侧特征树。不使用它的名称、图标、文案原文或 `.mcad` 工程格式。产品名仍是 Wego CAD。

底层不换。几何继续是 Open CASCADE（occt-wasm，Worker 里按特征重放），画面继续是 Three.js WebGPU。新操作只是多几种特征，写进现有的 `features` 数组。

## 已经有的

拉伸、旋转、并集、差集、交集、圆角、倒角、抽壳、拔模、薄壁、片体、移动、复制、镜像、线性阵列、圆周阵列、三个基准面以及偏置、等分、斜面、多实体、撤销、STEP、缝合公差、按面剖分、点选单条边倒圆。

草图有矩形、圆、多段线、三点圆弧。没有尺寸约束求解器。

## 这一轮要补的功能

都用现有内核接口，失败时记在特征上，不把整棵树打断。

| 能力 | 做法 |
| --- | --- |
| 扫掠 | 一条封闭截面沿另一条草图路径扫过。路径可以不封闭。 |
| 放样 | 两个或更多封闭截面连成实体。截面按选择顺序。 |
| 推拉面 | 点一个面，沿法向推出或压入，记成特征。改距离会重放。 |
| 分割 | 用一个基准面把实体切开，保留两侧或只留一侧。 |
| 测量 | 两点或两条边的距离、两条边的夹角。只显示，不进特征历史。 |
| 剖视 | 视口里用一个平面裁开模型，方便看内部。不改几何。 |

草图补直线和样条，仍是现在的点击绘制，不加约束求解器。

## 这一轮的页面

- 视口改成深色工作区，实体仍是着色加边线。网格和基准面压低对比。
- 左上放视图方块，点一面切到前、后、左、右、上、下，点角切回轴测。现在的文字按钮去掉。
- 工具轨按草图、成型、修饰、变换分组，扫掠和放样放进成型。
- 增加选择过滤：实体、面、边、草图。过滤开着时，点选只命中这一类。
- 右侧仍是特征树和属性。推拉距离、扫掠路径、放样截面都在属性里改。

## 这一轮不做

- 工程图、DXF 编辑、标注出图
- 尺寸约束求解，以及靠约束驱动的草图联动
- IGES、Parasolid、3DM、STL 转实体、DWG
- 拔模分析、斑马纹、壁厚云图
- CAM、CAE、装配
- 对方的品牌、图标和工程格式

这些留在规格里，避免和「内核不用动」打架。约束求解器和工程图都是内核外面的新系统。

## 怎么算通过

- 内核冒烟：扫掠和放样体积大于 0 且稳定；推拉面改变体积；分割后两侧体积之和接近原体积。
- 浏览器：原有拉伸、圆角、偏置平面仍通过；视图方块能切到顶视；选择过滤能挡住误选。
- 通过后提交到当前仓库的 `main`，并更新 `CHANGELOG.md` 和 `docs/设计方案.md`。
